# gitopsgke ♐👮
gitopsgke : | GitOps on GKE | Deploy workload, Rolling Updates, Policy Controller, Mutation Support, Synchronization Status |


## Objectives
- To update deployments imperatively and transition to declarative policy-based mutations using GitOps (Config Sync) and Policy Controller.
- Perform a zero-downtime rolling update of a GKE deployment image and monitor the rollout status.
- Configure Policy Controller mutations in a GitOps configuration repository.
- Enable and push a GitOps policy to trigger automated synchronization.
- Verify policy-driven pod mutation for GKE compute class selection.
